# Олег — платформы

- **ВКонтакте** — личная страница (не группа). Ссылка/ID: _уточнить_.
- **Telegram** — канал. Username/ссылка: _уточнить_.
  - Публикация: через Bot API, токен бота — переменная `OLEG_TG_BOT_TOKEN`
    в `.env` (создать отдельного бота или использовать существующего —
    решить перед Фазой 4).

Оба формата — личный бренд, не студия/группа. Это важно для Стратега:
тон "от первого лица", не "от компании".
