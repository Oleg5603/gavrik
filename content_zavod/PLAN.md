# ContentZavod — план построения

Ветка `ContentZavod` в репозитории `gavrik` — изолированно от продакшн-бота
(`master`), чтобы не сломать уже работающий пайплайн для Светланы
(`VK_POSTS`, `svet_bot`) во время разработки.

## Фаза 0 — Основа (эта ветка, сейчас)
- [x] Отдельная ветка `ContentZavod`
- [x] `SOURCE.md` — сохранена выжимка методологии из вебинара
- [x] `ROLES.md` — роли, порядок, передача данных
- [ ] Структура `clients/<имя>/` с шаблонами `brand.md`/`strategy.md`/`platforms.md`
- [ ] Заполнить `clients/oleg/brand.md` и `clients/svetlana/brand.md` реальными данными (нужен вход от Олега — см. открытые вопросы ниже)

## Фаза 1 — Стратег (разово на клиента)
- Скилл/промпт: бренд+продукт+боли ЦА → рубрики + тон + запрещённые темы
- Проверка на одном клиенте (Светлана, т.к. там уже есть данные — сайт,
  отзывы, VK-группа misemia) вручную, до автоматизации остальных

## Фаза 2 — Генератор идей + Сценарист + Мастер хуков
- Реализовать как последовательность промптов через существующий `_ask_ai`
- Выход: 5-7 тем/неделю → на каждую сценарий → на каждый сценарий 3 хука

## Фаза 3 — Конвейер форматов
- Сценарий+хук → 3-4 черновика (пост ВК, пост ТГ, карусель, видео-сценарий)
- Показ в Telegram пачкой, как `/newpost`, но на всю неделю разом

## Фаза 4 — Редактор + Публикатор
- Одобрение пачкой (кнопки: одобрить/править/отклонить на черновик)
- Публикация по расписанию недели (переиспользовать логику `svet_bot`
  для ВК; для Telegram — прямая публикация через Bot API в канал клиента)

## Фаза 5 — Аналитик (после того как Фазы 1-4 стабильно работают руками)
- Сбор охватов раз в 1-2 недели, заметки в `strategy.md`
- Сознательно отложено: без стабильного конвейера аналитика бессмысленна

## Явно вне рамок (пока)
- Лид-магнит и автоворонка продаж (модули 4-6 методики) — это уже про
  монетизацию трафика, а не про производство контента; отдельная задача
  после того, как сам конвейер докажет себя на 2-3 неделях реальной публикации
- Нейро-аватары/видео-генерация — упомянуты в источнике как опция, не нужны
  для MVP (текст+карусели уже дают формат без камеры)
