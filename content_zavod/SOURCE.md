# Источник методологии

Извлечено из вебинара "Вайп на миллион" (запись `соцсети 1.avi`, ~2ч28м,
2026-07-15) — по сути презентация платного курса, но сама методология
поверх агента на Claude Code полезна и без покупки курса.

## Заявленная причина провалов "в лоб"

Автор потратил ~400 000 ₽ и 2 месяца на "контент-машину" (личный опыт, найм
сценаристов/монтажёров), результат — 49-125 просмотров. Причина: контент без
фундамента (без стратегии/бренд-контекста) — "лента превращается в мусорное
ведро". Пять типичных ошибок, которые в это приводят:
1. Снимать что попало без единой линии/структуры.
2. Копировать чужой залетевший формат один в один (не подходит другому
   человеку/экспертизе/подаче).
3. Бессистемный постинг (рывками, потом забросил).
4. Работать на силе воли (кончается через ~7 дней).
5. Слепой "конвейер ради конвейера" — количество без смысла.

## 5(+1) модулей методики (без воды)

- **Шаг 0 — агент-фундамент.** Один раз настраивается агент (Claude Code) с
  памятью о бренде/продукте/аудитории. Дальше он не требует объяснять
  контекст заново на каждый запрос.
- **Модуль 1 — распаковка идеи.** Скилл превращает бренд/продукт/боли
  аудитории в контент-стратегию: рубрики, тональность, "упаковку" эксперта.
- **Модуль 2 — сценарий.** Один сценарий (структура) → скилл "конвейер"
  раскладывает в 4 формата разом: пост, короткое видео (рилс) со сценарием
  хука, карусель, статья/лонгрид. Экономия — не пишешь 4 текста, пишешь 1
  сценарий с чёткой структурой.
- **Модуль 3 — марафон выкладки.** Публикация по готовому расписанию без
  ежедневного "а что сегодня писать" — контент собирается пачкой на
  7-10 дней вперёд.
- **Модуль 4 — лид-магнит.** Продукт/файл, который конвертит просмотры в
  заявки (без этого трафик есть, а заявок нет).
- **Модуль 5-6 — автоворонка и автопилот.** Автопостинг по расписанию,
  несколько аккаунтов, аналитика без ручного разбора.

## Скиллы, которые реально дают эффект (не сам факт публикации)

- **Распаковщик** — бренд/продукт → стратегия и рубрики.
- **Сценарист** — идея → структура сценария.
- **Конвейер форматов** — 1 сценарий → 4 единицы контента.
- **Мастер хуков** — первые 3 секунды/первая строка решают удержание,
  генерирует и тестирует несколько вариантов.
- **Аналитик роликов** — разбор, что зашло/не зашло, обратная связь в
  стратегию.

## Ключевой вывод для нашего построения

Автоматизировать стоит **конвейер** (идея → сценарий → форматы), но
**обязательно** сохранить два элемента, которые в записи объявлены
критичными для результата и совпадают с уже принятым в Гаврике принципом
"без подтверждения человека не публикуется" (см. `CLAUDE.md` в master):
человеческую правку/одобрение и периодический разбор результатов
(аналитика → корректировка стратегии). Голый автопостинг без этого — это и
есть тот самый провалившийся "контент-завод" из истории автора.
