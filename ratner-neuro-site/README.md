# НейроНавигатор — безопасный MVP

Информационный прототип для выбора срочности обращения к врачу. Не ставит диагноз,
не определяет локализацию поражения, не назначает исследования и не сохраняет ответы.

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
npm run build
```

Клинические формулировки и правила имеют статус `draft` до письменного утверждения
профильным врачом. Публикация требует медицинского, юридического и human approval.
