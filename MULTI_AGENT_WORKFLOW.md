# Оркестратор ПРОЕКТИРОВАНИЯ

Единая система управления всеми проектами. Внутри работает группа агентов «ПРОЕКТ».

Источник истины для ролей и правил — `multi_agent.py`. Там определены 13 ролей с контрактами входа/выхода и условиями завершения.

Основной поток разработки:

`Planner → Architect → Challenger → Developer → Reviewer → QA → Security → Controller → UX Tester → Protector`

Дизайнер и копирайтер подключаются оркестратором, когда задача содержит интерфейс или пользовательский текст.

## Quality gates

- Архитектура: вердикт Challenger и ручное подтверждение.
- Реализация: Approved от Reviewer и успешный QA.
- Релиз: Security, Controller, Protector и ручное подтверждение.
- Любое открытое замечание `critical` или `high` блокирует gate.

## Защита от циклов

- По умолчанию не более трёх итераций каждого цикла.
- После лимита работа останавливается и эскалируется человеку.
- Замечания имеют критичность и статус; закрытые замечания не поднимаются повторно без новых доказательств.
- Общий JSON-журнал хранит итерации, решения, подтверждения и историю событий.
